# Registros de decisiones de arquitectura

🇬🇧 [Read in English](../../adr/README.md)

Un archivo por decisión que costó tomar y costaría revertir. Cada uno registra
el contexto del momento, la decisión y lo que cuesta —incluidos los casos en
que el costo es real y aun así la tomamos.

Un ADR no se edita una vez aceptado. Si una decisión cambia, un ADR nuevo la
reemplaza y lo dice.
